Entry for the make.fun bounty "The Word You'd Delete From the Dictionary": the single word to erase from the dictionary forever is "irregardless" (12 characters).

## Why it works

"Irregardless" is a blend of "irrespective" and "regardless" that bolts a negative prefix onto a word that is already negative. Dictionaries only list it to mark it nonstandard, yet people reach for it exactly when they want to sound formal. Deleting it removes the one word that lets a speaker sound correct while being wrong twice over: wrong about the meaning, and wrong that the extra syllable helps. The joke lands the moment you read the word, because the word itself is the mistake.

```bash
python3 main.py
```
