Entry for the make.fun bounty "The Word You'd Delete From the Dictionary": the single word to erase from the dictionary forever is "supposably" (10 characters).

## Why it works

"Supposably" is what people say when they mean "supposedly" — a word that exists only to let a speaker sound certain while using the wrong word. Dictionaries only list it to mark it a nonstandard variant, yet it survives because it sounds almost right. Deleting it removes the one word that lets a speaker be confidently wrong about the very word they chose to sound confident. The joke lands the moment you read the word, because the word itself is the mistake.

## Run

```bash
python3 main.py
```

This writes the word to `/output/entry.txt`. The program validates the entry first: exactly one word, 1–77 characters, letters only, lowercase, no whitespace. Two runs produce byte-identical output ("supposably", verified 26 Nov 2026).
