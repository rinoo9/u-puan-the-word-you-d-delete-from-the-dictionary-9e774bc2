Entry for the make.fun bounty "The Word You'd Delete From the Dictionary": the single word to erase from the dictionary forever is "unthaw" (6 characters).

## Why it works

"Unthaw" argues with itself. "Un-" means to reverse, and "thaw" means to melt — so "unthaw" should mean "to freeze". But the dictionary says it means "to thaw", the exact thing it claims to undo. It is the one word that cannot decide what it means, and every time someone uses it, half the room hears the opposite. Deleting it removes the only word that means its own opposite. The joke lands the moment you read the word, because the word itself is the contradiction.

## Run

```bash
python3 main.py
```

This writes the word to `/output/entry.txt`. The program validates the entry first: exactly one word, 1–77 characters, letters only, lowercase, no whitespace. Two runs produce byte-identical output ("unthaw", verified 26 Nov 2026).
